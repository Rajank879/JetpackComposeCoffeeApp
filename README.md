📱 About The Project

This is a modern Coffee Shop Android App built using the latest Android technologies and best practices.

The project demonstrates how to build a scalable, maintainable, and production-ready app using:

* Clean Architecture
* MVVM + MVI pattern
* Jetpack Compose UI
* Pagination using Paging 3
* Dependency Injection with Hilt


✨ Features

* ☕ Browse coffee products
* 🔍 Search & filter functionality
* 📄 Pagination support (Paging 3)
* ❤️ Favourite products
* 🛒 Add to cart functionality
* ⚡ Smooth and modern UI with Compose

🧠 Architecture

This project follows Clean Architecture + MVVM with MVI approach

presentation/
 ├── ui (Compose Screens)
 ├── viewmodel
 ├── state (MVI)

domain/
 ├── usecases
 ├── models

data/
 ├── repository
 ├── remote/local sources
 
---

🔄 MVI Flow

User Intent → ViewModel → State Update → UI Render
